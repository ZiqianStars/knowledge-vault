### 抖音反爬链路（实测顺序）

1. `v.douyin.com` 短链 → 302 → `www.iesdouyin.com/share/video/<aweme_id>/` → 302 → `www.douyin.com/video/<aweme_id>`
2. `www.douyin.com` 直连返回 **JS VM 反爬壳**（`_$jsvmprt`），无内容
3. `iesdouyin.com` SSR 页有 `_ROUTER_DATA`，但**只有 app 配置，没有 item 数据**（item 由 XHR 客户端加载）
4. `aweme/v1/web/aweme/detail` 裸调 → `403 Blocked by ArgusSecurityPlugin Uifid Not Found`
5. `aweme/v1/web/aweme/detail` 用浏览器里的签名 URL + cookie → **size=0**（a_bogus 签名与 cookie/UA 绑定，不能外搬）
6. `web/api/v2/aweme/iteminfo` → `status_code 11110 encrypt_data_miss`

**唯一可行路径：浏览器自动化（bsk skill）**

- `bsk` CLI 在 `~/.local/bin/bsk`（v0.4.1），Chrome 扩展已连（instance `a834faee`，Chrome 156）
- 会话需 `bsk session start --browser <instance-id> --json` → 拿 `session_id`
- `bsk navigate` 后 `bsk cooperate enable --policy target` → 拿 `context_id` + `observation_id`
- ⚠️ **每次 `bsk evaluate` 都要新的 `cooperate sync`**（否则 `cooperation_sync_required`）；**同一 observation 只能用一次**
- ⚠️ **不要在 evaluate 里做深度 DOM 递归遍历** → DevTools channel 卡死，之后所有命令报 `cdp_failed / Previous operation is still settling`
  → 恢复：新建 `bsk session`（旧 session 的 tab 救不回来）
- `bsk debug request --part response` 的 body 会因 `body_limit` 被截断（`state: truncated`, `text: ""`），拿不到完整 JSON
- **可用的取数方式**：`bsk evaluate` 读 `document.body.innerText` —— 已包含标题、章节要点、点赞数、发布时间、作者、评论
