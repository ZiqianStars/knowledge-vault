### vault 注册方法（重要，勿重复踩坑）

`open -a Obsidian <folder>` **无效**（错误 `-10820`，Obsidian 未声明文件夹文档类型）；`obsidian://open?path=...` 对未注册 vault 也无效。

有效做法是写入注册表 `~/Library/Application Support/obsidian/obsidian.json`：

```json
{ "vaults": { "<16位hex>": { "path": "/绝对路径", "ts": 毫秒时间戳, "open": true } } }
```

写入前需先退出 Obsidian（`osascript -e 'tell application "Obsidian" to quit'`），再 `open -a Obsidian` 启动。启动后 vault 内会生成 `workspace.json`，即为加载成功的标志。
