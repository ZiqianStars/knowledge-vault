# T+1交易制度

> 原视频：[《股市生存指南》第4课，A股市场规则。](https://www.bilibili.com/video/BV1NNbK6KEEo) · B站 · 2分36秒 · UP：机油手_交易员版

## 一句话概括

> A股**不能当日买卖**：当天买入的股票，要等到**下一个交易日**才能卖出。这条规则决定了——**每一次买入，你都至少要承担一个隔夜的风险。**

## 核心内容

![[T+1交易制度-规则.jpg]]

*视频 01:30 —— T+1 是本课的「重点规则」，也是 A 股区别于很多海外市场的标志性制度。*

**规则本身很简单**：当天买入 → 下一交易日才能卖出。

**真正的含义在于它带来的后果**：

| 后果 | 说明 |
| --- | --- |
| **买入即承担隔夜风险** | 买入那一刻起，到下一个交易日开盘前，你无法退出。所有隔夜消息、外围市场波动、突发事件都由你承担 |
| **当天买入的仓位当天无法止损** | 这是最容易被忽略的一条。止损规则在「当天买入」这个场景下是失效的——见下方理解 |
| **决策必须前置** | 视频原话：「买入前一定要谨慎，想好自己能否接受至少隔夜持仓」 |

## 关键摘录

| 原文 | 我的想法 |
| --- | --- |
| 「你当天买入的股票要等到下一个交易日才能卖出。」 | 规则一句话，但它把「买入」这个动作的权重抬高了——**A股的买入是不可逆的，至少一天**。 |
| 「大家买入前一定要谨慎，想好自己能否接受至少隔夜持仓。」 | 把 T+1 的应对方法直接给了：**在下单前就问自己能不能接受隔夜**，而不是买完再后悔。 |
| 「当天买入的股票想卖出却操作不了。」 | 新手最容易被这条绊住。不知道规则的人会以为软件坏了。 |

## 我的理解

- **T+1 最重要的一条推论是：止损规则有盲区。** [[移动止损]] 讲的是「跌破止损位就卖」，但如果你**当天**才买入，当天是卖不掉的——止损位在买入当日形同虚设。这意味着 T+1 市场里的仓位管理必须更保守：**你要么接受买入当天完全暴露，要么就把单笔仓位压小**。
- 换个角度看，T+1 也是**对散户的一种保护**：它物理上阻止了「当天追高当天割肉」的日内反复操作，而这恰恰是散户亏钱最快的方式。规则同时是约束和护栏。
- 从制度对比看：很多海外市场是 T+0（当日可回转交易）。**这不是谁更「先进」的问题，而是交易频率的默认值不同**——T+1 强制降低了换手率，客观上偏向持有更久的人。
- 一个容易混淆的点：**T+1 限制的是「卖出」，不是「买入」**。当天买入 A 股后，你仍然可以继续买；也可以卖出**昨天及更早**买入的部分。理解这一点才不会误判自己的可操作范围。

## 可行动的结论

- [ ] 每次下单前加一句自检：「这笔我至少要拿到明天，我接受吗？」
- [ ] 检查自己的仓位规则：在无法当日止损的前提下，单笔仓位该压到多大？
- [ ] 把「当天买入不可卖」写进自己的交易清单，避免再次误判为软件故障
