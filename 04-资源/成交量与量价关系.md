# 成交量与量价关系

> 原视频：[《股市生存指南》第8课，看懂成交量](https://www.bilibili.com/video/BV1iXHa6kEVa) · B站 · 4分3秒 · UP：机油手_交易员版

## 一句话概括

> 成交量 = 一段时间内成交的**总手数**（1手 = 100股）。但它本身说明不了什么——**必须和价格趋势、所处位置结合**。同样一个「放量」，在高位和低位代表完全相反的事。

## 核心内容

### 一、成交量是什么

- **定义**：一段时间里股票买卖**成交的总手数**。成交必须买卖双方共同参与——**你买了一手，就必然有另一个人卖了一手**。
- **界面位置**：K 线图下方，以**柱状图**显示（见 [[股票软件界面速读]]）。
- **颜色**：红柱 = 当天股价上涨（买方力量更强）；绿柱 = 当天下跌（卖方力量更强）。

### 二、放量 / 缩量 / 天量 / 地量

| 术语 | 定义 |
| --- | --- |
| **放量** | 柱子比前一天（或前一段）高 → 量能放大 |
| **缩量** | 柱子比前一天低 → 量能萎缩 |
| **天量** | 成交量激增，达到**很长时间以来的最高值** |
| **地量** | 反过来，量能极度萎缩 |

量能放大首先意味着：**这只股票相比之前有更多资金关注，买卖更活跃**。

### 三、⭐ 成交量不能单独使用

必须与 **价格趋势** 和 **所处位置** 结合，才分析得出结​​论。

**（1）与价格的关联：量价齐升 vs 量价背离**

| 情况 | 特征 | 含义 | 比喻 |
| --- | --- | --- | --- |
| **量价齐升** | 股价稳步上涨，成交量**温和放大** | 上涨得到真金白银的支持，趋势健康、有持续性 → **健康的主升浪**，安心持有 | 爬山时呼吸均匀有力 |
| **量价背离**（顶背离） | 股价创了新高，但成交量**跟不上、反而萎缩** | 危险信号：上涨动力已经枯竭，趋势即将反转 → **必须高度警惕** | 喘不上气还在硬撑 |

**（2）位置决定性质——同样是放量，不同位置不同命运**

| 位置 | 放量意味着 |
| --- | --- |
| **高位**放巨量 | 可能是主力在热闹中**出货**，吸引你跟风接盘 |
| **低位**放巨量 | 资金**悄悄进场**，趋势启动的征兆 |
| **关键压力位**放量突破 | 才是真正的**冲锋号** |

### 四、从量价关系看顶和底

| 现象 | 特征 | 含义 |
| --- | --- | --- |
| **放量滞涨** | 出现天量，但**价格却涨不上去** | 狂欢达到顶点，聪明资金在热火朝天时快速离场 → 大概率处于**高位区间** |
| **地量见地价** | 成交量**极度萎缩** | 市场冷清到没人愿意卖、跌也跌不动，套牢的躺平不割肉，空方力量枯竭 → 大概率**底部**，可能出现转机 |

## 关键摘录

| 原文 | 我的想法 |

| 「成交量本身没有多大的意义，但是通过成交量与价格趋势以及所处的位置来看，就能发掘出市场的重大意义。」 | 全课的核心。单独一个「放量」是形容词，褒贬完全由位置决定。 |
| 「对于成交量的理解程度可以直接决定你操作的上限。」 | 视频对成交量的评价很高（「股价的汽油」），但真正决定上限的是**结合位置的能力**，不是看量本身。 |
| 「地量见地价……说明市场冷清到已经没有人愿意卖，跌也跌不动了。」 | 描述准确，但要小心推论——见下方理解。 |

## 我的理解

- 这一课的结构本身就是信息：**定义 → 单独无意义 → 必须与价格和位置结合**。前半段是铺垫，后半段才是内容。**成交量是形容词，不是名词**。
- 「**位置决定性质**」这条和 [[单根K线形态]] 里的「位置决定含义」是**同一条原理**。把它们并起来看会得到一条更普适的准则：**任何技术指标都只在特定位置下才有意义**。这大概是从第 6 课到第 10 课反复出现的暗线，值得单独记成一条原则。
- **「放量滞涨」是很有价值的顶部信号**，因为它抓住了本质：成交量记录的是资金行为。天量说明多空双方搏杀剧烈，而价格上不去，说明**卖方已经能吃掉全部买方**——这比任何滞后指标都直接。
- **「地量见地价」要谨慎使用**：它描述的是「跌不动」，但**跌不动不等于会涨**。地量之后完全可能长期横盘磨人。视频说「很可能出现转机」——但转机可能是横盘，不一定是反弹。这里容易一厢情愿。
- 两个自己该补的技术前提：**成交量会被除权、停牌、大宗交易扭曲**；另外界面上那两条量能均线（MA5/MA10）是给「放量/缩量」提供参照基准的，和价格的 MA 均线（见 [[移动平均线]]）用途不同，别混用。

## 可行动的结论

- [ ] 找一只最近大涨的票，把「价格创新高」与「成交量是否同步放大」对照，认出量价背离长什么样
- [ ] 随便找一天的天量，看它出现在什么位置（高位 / 低位 / 突破位），验证「位置决定性质」
- [ ] 定一条纪律：看到放量，**先问「这个位置放量意味着什么」**，不要直接当成利好
