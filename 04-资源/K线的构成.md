# K线的构成

> 原视频：[《股市生存指南》第6课，看懂K线。](https://www.bilibili.com/video/BV1xAbK6iEC8) · B站 · 3分49秒 · UP：机油手_交易员版

## 一句话概括

> 一根K线，就是把当天的**四个价格**画成一张图：**实体是开盘与收盘的差（结果），上下影线是盘中冲高回落的幅度（过程）**。

## 核心内容

### 四个价格 → 一根K线

以「长电科技」5月29日那根K线为例：开盘 **86.00**、收盘 **82.05**、最高 **89.77**、最低 **80.33**。

| K线元素 | 对应 | 例子中的值 |
| --- | --- | --- |
| 垂直线的**最高点 / 最低点** | 当日最高价 / 最低价 | 89.77 / 80.33 |
| 与垂直线**垂直相交的两条线** | 开盘价 / 收盘价 | 86.00 / 82.05 |
| 两条线之间围成的**矩形** | **实体** | — |
| 实体**上方**的细线 | **上影线** = 最高价 − 开/收 中较高者 | — |
| 实体**下方**的细线 | **下影线** = 开/收 中较低者 − 最低价 | — |

### 颜色：谁在上面由涨跌决定

| 当天 | 关系 | 收盘价位置 | 颜色 |
| --- | --- | --- | --- |
| **上涨** | 收盘价 > 开盘价 | 在上面 | **红色** |
| **下跌** | 收盘价 < 开盘价 | 在下面 | **绿色** |

### 实体高度与影线长度各代表什么

| 元素 | 度量的是 | 越大意味着 |
| --- | --- | --- |
| **实体高度** | 当天的**涨跌幅度**（收盘越远离开盘，实体越高） | 单向力量越强 |
| **上影线 / 下影线长度** | 盘中的**波动幅度** | 过程越剧烈（冲高回落 / 探底回升） |

### 从单根K线读情绪

| 形态 | 特征 | 含义 |
| --- | --- | --- |
| 开盘后**一路上涨、收盘即最高** | 开盘价 ≈ 最低价，收盘价 ≈ 最高价（几乎没有影线） | **非常强势**，很多人买、股价被顶上去了；甚至触及涨幅上限 → **涨停板**，情绪非常好 |
| 开盘上涨但**快收盘时回落** | 收盘价与最高价之间拉出**很长的上影线** | 有人往上冲买，**更多的人在拼命卖**，越卖越低 → 当天情绪不妙，**后续可能下跌** |

## 关键摘录

| 原文 | 我的想法 |
| --- | --- |
| 「K线图则是直观地反映出了这四个数据的实现现状。」 | K线不是新信息，只是**四价的可视化压缩**。理解这一点就不会把它神秘化。 |
| 「实体柱状图的高低取决于当天股价的涨跌幅度。」 | 实体量的是**结果强度**，影线量的是**过程波动**。这两者分开度量，是读 K 线的关键分界。 |
| 「线越长说明过程波动越大。」 | 一句话点出影线的意义。很多人只看红绿，完全忽略了影线——那等于丢掉了「盘中发生了什么」这一半信息。 |

## 我的理解

- K线本质上是**把一天的多空博弈压缩成一张图**：开、收是「结果」，高、低是「过程」。实体读结果强度，影线读过程波动——有了这个框架，任何一根 K 线都能看出点东西。
- **一个最容易忽略的区别：实体方向只说「当天涨还是跌」，影线才说「盘中发生了什么」。** 同样都是绿K，带长上影线的绿K（冲高回落，卖压出现）和光头光脚绿K（一路阴跌）含义完全不同。只看颜色不看形状，等于只读了一半。
- 对长上影线的解读要保持警惕：视频说「后续可能下跌」，这是**概率倾向，不是确定信号**。长上影也可能是洗盘。单根 K 线的信息量本来就有限——这正是下一课要讲「形态」、以及后面要讲多根组合的原因。
- 一个需要自己补上的边界：**A股涨跌停会扭曲K线形态**。涨停时可能出现全天「一字板」（开 = 收 = 高 = 低，实体退化成一条线），这时「实体高度 = 涨跌幅度」的读法要换成「封板强度」的判断。
- 最重要的一条自我提醒：**K线不预测未来，它只是把已经发生的交易画出来**。从它身上读到的是「参与者的行为痕迹」，而不是「明天的价格」。

## 可行动的结论

- [ ] 随便挑一只票的某一天，把当天的开/收/高/低四个数字找出来，对着 K 线逐个指认一遍
- [ ] 找两根「都是绿」的 K 线对比：一根光头光脚，一根带长上影线，说清它们的区别
- [ ] 找一只涨停的票，看它的 K 线是不是变成了「一字板」
