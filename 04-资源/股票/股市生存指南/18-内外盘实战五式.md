# 内外盘实战五式

> 原视频：[《股市生存指南》第18课，看懂主力欺骗&内外盘实战解析5式](https://www.douyin.com/video/7652316122221530378) · 抖音 · 5分31秒 · UP：机油手

## 一句话概括

> [[17-内盘与外盘]] 讲「内外盘是什么」，本课讲「它怎么被做假、以及五种常见组合怎么读」。核心不是记住五个结论，而是看懂**同一个「外盘远大于内盘」，配上量价齐升／缩量滞涨／放量下跌，含义完全相反**。作者一面演示主力如何用 1 万手卖单钓出散户吃掉自己摆好的 5 万手卖单，一面又承认「有主力也无法明确主力当时的真实意图」——五式是线索，不是公式。

## 核心内容

### 一、本课定位

- 第 17 课的续集：从「定义与统计机制」进入「操纵手法与实战判别」。
- 结构：先推演主力怎么把内外盘做成反的（00:25–01:50），再回答「既然能做假为什么还要学」（01:50–02:20），最后给出五种常见组合（02:20–05:05）。
- 作者结语给了一个平衡判断：**操纵有成本，所以多数时候数据仍可信**。

### 二、⭐ 主力怎么把内外盘做成反的

**出货推演（把内盘做成外盘）**

1. 假设手上有 **100 万手**筹码要出。不能直接砸——量能一带出来可能引发踩踏，连砸两个跌停都出不完。
2. 先拆成小笔慢慢卖 → 内盘（主卖）数据越来越大 → 散户可能「原地多转空」跟着砸盘。
3. 于是**换账户往上方挂 5 万手卖单**，再用多笔中小单去扫这个大单 → 成交明细上出现一排红色（主动买），做出「压力位即将突破」的表象。
4. 量能带出来后，**仅用 1 万手卖单**就吸引无数散户吃掉提前摆好的 5 万手卖单。
5. 如此循环，股价甚至微微上涨、成交明细全是主买 → 散户看「外盘远大于内盘」继续放心持有；打开龙虎榜，主力只是做了个 T —— 实际出货目的已经达成。

### 三、既然能做假，为什么还要学

作者的观点（**观点，不是事实**）：炒股不同于投资，「这是个互相掏兜的游戏」。你想从对手盘赚钱，就必须明白他的所有意图；而弄明白的前提是搞懂机制——「如此你才有活下去的机会」。

> 这一段是视频的方法论立场：学指标不是为了照信号下单，而是为了**理解对手盘可能怎么利用这个信号**。

### 四、⭐ 内外盘实战五式

视频先写教科书式基准：**外盘大于内盘 → 股价上涨；内盘大于外盘 → 股价下跌**。然后拿现实情况逐一对照：

| 式 | 组合 | 作者判读 | 备注 |
| --- | --- | --- | --- |
| 一 | 外盘远大于内盘 + **量价齐升** | **真拉升** → 右侧买点 | 最健康的上涨 |
| 二 | 外盘远大于内盘 + **不涨反跌（缩量/小阴/平盘）** | **压价吸筹** → 左侧铺底仓 | 大单压盘、小单吃货 |
| 三 | 外盘远大于内盘 + **放量下跌** | **主力出货** → 跑 | 与第二式关键区别在「放量」 |
| 四 | 内外盘均衡 + 股价不动 | **观望为主** | 多空均衡，或主力高度控盘 |
| 五 | 内盘远大于外盘 + **不跌反涨（看位置）** | **灵活应对** | 低位区分真承接 / 假承接 |

![[内外盘实战-五式总表.jpg]]

*视频 05:05 —— 完整的五式对照表，顶部写「外盘大于内盘，股价上涨；内盘大于外盘，股价下跌」，每行末尾红色标注应对方式。*

**逐式要点**

- **第一式 · 真拉升**：买盘真金白银往里冲、卖盘被轻松吃掉、成交量同步放大、市场合力做多 → 趋势最强阶段，右侧交易者的买点。
- **第二式 · 压价吸筹**：前提必须是**缩量小阴或平盘**。典型形态是「大单压盘、小单吃货」，有人不想让股价涨，在低位偷偷收集筹码。操作是加自选盯着，等右侧信号；左侧选手可以开始铺底仓。
- **第三式 · 出货**：与第二式同是外盘大，但**放量**是关键差异。股价在跌却有大量买盘，极可能是大单压盘 + 多账户小单买入，制造外盘极大的假象吸引跟风盘介入，实际在派发。作者提醒要考虑承接力度与「借盘方隔日多杀多」的可能，**风险极高**。
- **第四式 · 均衡不动**：两种解释都说得通——明面上多空均衡、无明确主力行为；也可能是主力高度控盘、浮筹极少，无需对倒，等一个契机「旱地拔葱」。所以结论是观望。
- **第五式 · 看位置**：内盘数据很大但不拉升、小单连砸不破 → **假承接**，有人在吸引接盘；若回调够深、在低位出现「内盘很大（割肉恐慌持续）但股价不跌反涨」→ **真承接**，才可能是吸筹。区分变量是**位置 + 价格反应**。

### 五、结语：什么时候数据仍可信

- 作者承认内外盘数据容易被「装夹造假」，但补充：**一般连续成交、且成交稳定的个股，内外盘数据还是比较真实的**。
- 只有特殊情况下才会有人上手法；多数时候不会轻易上手，因为**操纵数据确实需要成本**。

## 实用建议

1. **先判重量，再判方向**：同一组内外盘数字，缩量滞涨与放量下跌是两种完全相反的结论——先看成交量。
2. **第五式必须看位置**：低位「内盘大但不跌反涨」才可能是真承接；高位同样形态更可能是假承接。
3. **把五式当排查清单，不当买卖信号**：作者自己说「有主力也无法明确真实意图」，任何一式都要结合趋势、位置与其他证据。
4. **警惕拟人化叙事**：不要把每次盘口异常都解释成「主力在做局」；无法证伪的解释不产生可执行的决策。
5. **保持作者那条底线**：连续成交、成交稳定的个股，内外盘数据相对可信；异常放量、封板、对倒痕迹明显时才启用怀疑模式。
