# 布林线BOLL

> 原视频：[《股市生存指南》第34课，看懂布林线（BOLL）](https://www.douyin.com/video/7669003887025687862) · 抖音 · 7分21秒 · UP：机油手

## 一句话概括

> 布林线 = 一条**动态价格通道**：中轨是 20 日均线（多空分水岭），上下轨 = 中轨 ± 2 倍标准差，约 95% 的价格落在通道内。带宽扩张＝趋势加速，极度收窄（缩口）＝变盘临近但不预示方向。**A 股不能把触及下轨当买点**——作者给的数据是 A 股跌出下轨后风险约 14%、美股仅约 3%，原因是单边做多、牛短熊长、政策底先于市场底。

## 核心内容

### 一、构造：三轨与 95% 的统计含义

- 本质：通过构建一个**动态价格通道**反映价格波动范围和相对高低，看起来像带子，也叫布林带。
- 电脑版同花顺日 K 界面右键「常用线型与指标」可切美国 K 线 + 布林带查看放大版。

![[布林线-三轨结构.jpg]]

*视频 02:35 —— 日 K 界面显示 BOLL(20,2) 三轨与数值，画面标注上轨（短期天花板/动态压力位）、中轨（多空分水岭，本质 20 日均线）、下轨（地板/动态支撑位）。*

| 轨道 | 含义 | 作用 |
| --- | --- | --- |
| **上轨** | 股价短期天花板 | **动态压力位**，涨到这里容易承压回落 |
| **中轨** | **多空分水岭**，本质是 **20 日均线**（20 天平均持仓成本） | 20 线也叫生命线 → 直接用来定义趋势强弱 |
| **下轨** | 股价地板 | **动态支撑位**，跌到这里一般有一定支撑 |

- 构造公式：**上轨 = 中轨 + 2×标准差；下轨 = 中轨 − 2×标准差**。
- 依据：统计上约 **95%** 的价格数据落在 2 倍标准差范围内 → 上下轨定义了**价格运行的常态区间**。

### 二、开口与缩口

- **开口（带宽扩张）**：股价波动剧烈、振幅变大 → 标准差变大 → 通道变宽 → 意味着**趋势加速**。
- **缩口（通道收窄）**：股价趋平静、振幅变小 → 标准差变小 → 通道收窄。
- **极度缩口**：市场波动降至极低、多空趋于平衡，如同弹簧被压缩 → 多预示着**即将选择方向**。
- ⚠️ **缩口本身不预示方向** → 应等待价格**放量突破上轨或跌破下轨**后再行动。

### 三、支撑压力与滞后性

- 下跌时，**中轨和下轨**都起支撑作用；上涨时，**中轨和上轨**都起压力作用——原理与均线相同。
- **布林线基于收盘价计算，具有明显滞后性**（视频末尾再次强调）。

### 四、⭐ A 股 vs 美股：为什么不能照搬

- 视频引用一项**中美大盘指数长达 5 年的数据对比研究**：A 股布林带风险约 **14%**，美股仅约 **3%**。
- 市场观点形容：美股跌出下轨后常能反弹至上轨；A 股跌出布林线后**反弹往往较弱、容易被中轨压制**。
- 作者给出三个原因：

| 原因 | 机制 |
| --- | --- |
| **1. 单边做多为主** | A 股本质做多才能赚钱，跌破下轨后缺少空单平仓的买入力量，反弹只能靠新资金主动买盘 → 力量单一薄弱 |
| **2. 牛短熊长** | 多数时间震荡或下跌；触及下轨时中轨通常仍在向下运行 → **向下倾斜的均线是压制而非牵引**，反弹到中轨等于逆水行舟 |
| **3. 政策底先于市场底** | 跌破下轨常伴随恐慌杀跌，国家队/政策资金入市托底，目标是防系统性风险而非拉升 → 反弹到中轨（回归合理位）后买入动力减弱，反弹戛然而止；对面市场更多用回购/流动性注入平抑波动，持续且无特定目标价，中轨阻碍较小 |

- **结论**：A 股不该把**触及下轨**当买入信号，应把**股价有效站稳并带动中轨由跌转涨**作为趋势反转的确认。

### 五、四步验证法 + 失效边界

1. **看中轨方向**
2. **看带宽状态**
3. **看量价配合**
4. **看指标共振**

**失效边界**：布林线是滞后指标，用过去 20 天价格计算。在 A 股突发重大利空/利好的**跳空缺口行情**中会**完全失效**——股价可能直接跳穿轨道，此时**严禁依据布林线逆市抄底或逃顶**。

## 实用建议

1. **先看中轨方向**：中轨向下时，下轨的「支撑」要打折看。
2. **缩口等突破**：变形到极窄时别猜方向，等放量突破上轨/跌破下轨。
3. **A 股触下轨不是买点**：等站稳且中轨由跌转涨再确认。
4. **跳空行情直接停用**：重大消息导致的跳空会穿透轨道，指标此时无意义。
5. **四步清单**：中轨方向 → 带宽 → 量价 → 指标共振，缺一不可。
