# 筹码分布

> 原视频：[《股市生存指南》第35课，看懂筹码分布](https://www.douyin.com/video/7670557631219567891) · 抖音 · 6分28秒 · UP：机油手

## 一句话概括

> 筹码峰是**全市场持仓成本的可视化地图**：纵轴股价、横轴筹码数量，红色获利盘、蓝色套牢盘，最高的柱子是筹码峰、凹陷处是筹码谷，黄线是市场平均成本。**它很难作假，但不是真实持仓数据**——软件按「所有持仓者按当日换手率等比例卖出」估算。价格在成交密集区上方遇套牢盘压力、下方遇获利盘支撑；筹码永远在**发散→密集→再发散**中循环。

## 核心内容

### 一、怎么调出来

- 同花顺手机端：日 K 界面 → 右下角「功能」→ 选择「筹码分布」。
- 电脑版更直观，快捷键 **F7** 看全景。
- 其他软件位置不同，基本都在日 K 界面。

### 二、⭐ 它是什么：资金地图，不是交易所数据

- 老股民说「筹码分布是主力透视镜」，不算夸张——**K 线可以画，但全市场持仓成本藏不住**，成交明细摆在那里，花时间谁都算得出来。
- 因为统计的是**每一笔真实成交的结果**，筹码峰**很难被作假**（但不绝对，盘子够大才基本没问题）。
- 通俗定义：把**所有投资者的持仓成本明明白白摊开**的一张资金地图。
- 核心功能：判断**动态支撑位和压力位**、识别主力**吸筹/洗盘/拉升/出货**的完整动作、大致推算主力平均成本。
- **A 股专属性**：这是本土发明的指标，特别适配 A 股生态——美股以机构长期持股为主、换手慢、峰形变化不明显；A 股散户多、换手活跃，主力每一步都会在筹码上留下清晰痕迹，所以实战价值反而**比很多海外经典指标更高**。

### 三、怎么读：坐标、颜色、峰谷、黄线

> 本课视频轨未取到画面（只拿到音频），故不配截图；以下读图要素按口播整理。

| 要素 | 含义 |
| --- | --- |
| **纵轴** | 股价，与左侧 K 线刻度一一对应 |
| **横轴** | 筹码数量；柱子越长＝该价位堆的筹码越多、持仓的人越多 |
| **红柱（获利盘）** | 持仓成本**低于**当前股价，拿着的人现在赚钱 |
| **蓝柱（套牢盘）** | 持仓成本**高于**当前股价，拿着的人现在亏损 |
| **筹码峰** | 柱子最高、最突出的地方＝成交最密集的成本区 |
| **筹码谷** | 两峰之间柱子特别短、凹进去的地方＝**成交稀少的价格真空区** |
| **黄线** | 市场**平均持仓成本线**（所有流通筹码的平均买入价）；股价在上方＝多数人赚钱，下方＝多数人被套 |
| **收盘获利比例** | 当前价位赚钱的筹码占总流通盘的百分比 |

**90% / 70% 筹码**：可自行切换观察范围。
- 90% 反映**市场整体**成本分布；70% 更聚焦**核心活跃筹码**。
- 本质类似「去掉一个最高分去掉一个最低分」：90% 剃除价格最高和最低各 **5%** 的极端筹码；70% 各剃除 **15%**。
- **价格区间**：当前筹码分布的价格范围。
- **集中度**：数值越小＝筹码越集中、主力控盘概率越高；越大＝筹码越分散、散户扎堆，行情容易拧巴。**但必须结合股价历史分位**——高位单峰聚集多是筹码派发完毕（下集展开）。

### 四、⭐ 关键澄清：它是算法估算，不是真实持仓

- 很多朋友（包括老股民）以为筹码峰是交易所给的真实持仓数据——**其实不是**。
- 软件公司拿不到每个股民账户的真实持仓，只能**靠算法估算**。
- **核心逻辑**：默认所有持仓者都会按当日换手率**均匀等比例**卖出筹码。
  - 例：某股当日换手率 **13%** → 软件默认每个持仓者都卖出了自己仓位的 13% → 把这些卖出的筹码全堆到当日成交价上 → 一天天累积形成各价位的筹码堆积。
- **假设的偏差**：现实中有人死拿不卖、有人全仓进出，不可能所有人均匀卖出。
- 但作为**历史成交密集区的可视化工具**，价值是实实在在的——某价位成交量越大、沉淀资金越多，股价再次回到这里时：
  - **往上走** → 遇套牢盘解套抛压 → 形成**压力**；
  - **往下走** → 遇获利盘回补买盘 → 形成**支撑**。
  - 这就是筹码峰支撑/压力作用的底层逻辑。

### 五、⭐ 筹码的永恒循环

> **发散 → 密集 → 再发散 → 再密集**

- **大跌时**：筹码散在各个高位 → **发散**。
- **跌到底部长期横盘**：上方套牢盘慢慢割肉，筹码集中到低位 → 形成**密集峰**。
- **主力拉抬股价**：筹码随上涨逐步向上转移 → 从**单峰变多峰**，再到高位重新密集。
- 整个过程就是主力**从吸筹到出货**的完整闭环。

**动态回溯**：手指选中一根 K 线左右滑动，筹码峰会随对应日期动态变化 → 可复盘过去每一天的筹码结构、看筹码怎么一步步转移；也可切换到周线/月线看中长期布局。实战应用留到第 36 课。

## 实用建议

1. **记住它是估算**：不要把它当股东名册，尤其对大股东持仓、限售股无能为力。
2. **先看黄线位置**：股价上方＝多数人赚钱，下方＝多数人被套，这是最快的市场状态判断。
3. **峰是成本密集区、谷是真空区**：谷区价格往往走得快（没什么筹码阻碍）。
4. **看筹码循环阶段**：低位单峰密集（可能吸筹完毕）→ 上移多峰（拉升派发中）→ 高位密集（可能派发完毕）。
5. **集中度必须结合历史分位**：高位的低集中度不是好事。
6. **用动态回溯复盘**，别只看当天静态图。
