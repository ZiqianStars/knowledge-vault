# 集合竞价

> 原视频：[《股市生存指南》第3课，股票的交易场所](https://www.bilibili.com/video/BV1zmtN6XEE1) · B站 · 8分3秒 · UP：机油手_交易员版

## 一句话概括

> 早盘集合竞价决定当天开盘价，但它**分两段**：9:20 之前可以撤单，主力爱在这里挂假单诱多；**9:20 之后不能撤单，那才是真实的开盘预期**。

## 核心内容

![[集合竞价-交易时间轴.jpg]]

*视频 04:40 —— A股一天的交易时间轴，精确到分钟的「战斗时刻」。*

### 一天的时间结构

| 时段 | 名称 |
| --- | --- |
| **9:15–9:25** | 早盘集合竞价（决定开盘价） |
| 9:30–11:30 / 13:00–14:57 | 连续竞价（正常交易时间） |
| **14:57–15:00** | 尾盘集合竞价（决定收盘价） |
| 15:05–15:30 | 盘后固定价格交易（科创板 / 创业板，按收盘价成交） |

交易日为周一至周五，法定节假日与周末不开市。

### 关键：早盘集合竞价的两个阶段

| 阶段 | 规则 | 意味着什么 |
| --- | --- | --- |
| **9:15–9:20** | 可以挂单，**也可以撤单** | 主力常在这里挂涨停价假单吸引散户跟风，然后在 **9:19 突然撤单** —— 典型的诱多 |
| **9:20–9:25** | **只能挂单，不能撤单** | 撤不掉，所以这里的价格和成交量才是**真实**的，是市场真实的开盘预期 |

> **看集合竞价，重点看 9:20 之后的走势。9:20 之前的价格参考意义不大，别被假单骗了。**

![[集合竞价-对比连续竞价.jpg]]

*视频 06:36 —— 集合竞价与连续竞价的成交机制对比。*

### 连续竞价的成交原则：价格优先、时间优先

- **价格优先**：买价更高 / 卖价更低的一方优先成交
- **时间优先**：价格相同时，先挂单的优先成交

### 市价单 vs 限价单

见 [[04-市价单与限价单]] —— 第 4 课有更完整的展开（含「限价单为什么总不成交」），此处不重复。

其中一条与本节直接相关：**限价单在早盘竞价阶段容易失效**——按 9:19 的假价位挂单，主力撤单后价格回落，你的单子就废了。

## 关键摘录

| 原文 | 我的想法 |
| --- | --- |
| 「9:20 分之后才是市场真实的开盘预期。」 | 全课最值钱的一句。它把竞价从「一段模糊的盘口」切成了「前半段可能是假的、后半段是真的」。 |
| 「主力会在这里挂假单……然后在 9:19 分突然撤单。」 | 为什么能骗人？因为 **9:20 前撤单零成本**。见下方理解。 |
| 「价格优先、时间优先。」 | 八个字解释了所有「为什么我的单子不成交」。特别是「时间优先」——同样的价格，早挂的人赢。 |

## 我的理解

- **9:20 这个分水岭是本课最实用的知识点。** 知道它之后，看到 9:19 的涨停挂单就不会冲动——那可能只是三分钟后就会消失的假单。
- 可以往上提炼一层：**主力之所以能诱多，是因为 9:20 之前撤单不花成本。任何「零成本可撤回的信号」都不可信**。这条准则不止适用于集合竞价——喊单、试盘、口头承诺，都是同一个结构。这是我认为这一课最有迁移价值的地方。
- 市价单/限价单的区别被大多数人低估。两者的风险恰好相反：**限价单的风险是「不成交」，市价单的风险是「成交在坏价格」**。新手最常见的错误是——想确保成交却用了限价单，想控制价格却用了市价单。
- 视频对**尾盘集合竞价（14:57–15:00）只提了一句，但它同样决定收盘价**，也是资金做收盘价的地方。值得单独留意，甚至有独立成一课的价值。

## 可行动的结论

- [ ] 明早开盘前观察一次：记录 9:19 和 9:23 两个时点的挂单价格/数量，亲自验证「前半段假单」的说法
- [ ] 检查自己的挂单习惯，明确写下：什么情况用限价单、什么情况用市价单
- [ ] 记住三个时间点：9:15–9:25 早盘竞价 / 14:57–15:00 尾盘竞价 / 15:05–15:30 盘后固定价格
