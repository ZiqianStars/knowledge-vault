# KDJ

> 原视频：[《股市生存指南》第33课，看懂短线指标之王KDJ](https://www.douyin.com/video/7667660486690868530) · 抖音 · 4分34秒 · UP：机油手

## 一句话概括

> KDJ 是**震荡类随机强弱指标**，专门捕捉短期高低拐点，灵敏度极高。三根线中 K 是快线、D 是慢线、J 是超前线；金叉越靠下越有效、死叉越靠上越有效。与 [[32-RSI与MACD|RSI]] 的分工是：**RSI 看力度与趋势强弱，KDJ 看速度与短线反转**；波段交易者可用「RSI 定方向 + KDJ 找入场」的组合。

## 核心内容

### 一、定位与三根线

- 括号里的三个数字分别对应：**计算周期、K 值平滑周期、D 值平滑周期**。
- 作者本期**不讲计算公式**，用比喻：不懂发动机原理不耽误拿驾照。
- KDJ 属于**震荡类随机强弱指标**，专门捕捉短期高低拐点，反应极灵敏。
- 三根线按颜色与数字一一对应：

| 线 | 特点 | 称呼 |
| --- | --- | --- |
| **K 线** | 波动较快 | 快线 |
| **D 线** | 平滑过滤噪音、作基准 | 慢线 |
| **J 线** | 波动最夸张 | 超前线 |

- 金叉 / 死叉与 MACD 同理，但**位置判断相反于直觉**：
  - **金叉越靠下，信号越有效**（D<20 为超卖区，下跌动能接近枯竭 → 可能反弹）；
  - **死叉越靠上，信号越有效**（D>80 为超买区，上涨动能接近枯竭）。
- **J 值超出 100 或小于 0** 为「负值/超买」极端状态 → KDJ 同样会进入**钝化**：强趋势中超买信号反而是价格强势的体现（与 RSI 机制相同）。

### 二、⭐ RSI 与 KDJ 怎么选

| | RSI | KDJ |
| --- | --- | --- |
| 反映 | **力度** | **速度** |
| 特性 | 相对平滑 | 灵敏度极高，频繁给交叉信号 |
| 适合 | **判断中短期趋势强弱与持续性** | **捕捉短线快速反转机会** |
| 使用者 | 波段 / 中线交易者 | 短线交易者 |

- 两者工作机制近乎一样，区别在**原理和意义**：都基于价格制作。
- KDJ 同样可用**钝化消失**和**背离**信号（见 [[32-RSI与MACD]]）。

### 三、⭐ 组合用法（本课最实用）

- 短线交易者：**首选 KDJ**，重点关注 K/D 交叉，尤其 **20 以下低位金叉**或 **80 以上高位死叉**。
- 波段/中线交易者：**首选 RSI**判断趋势强弱，辅以 KDJ 找入场点。
- 组合流程示例：
  1. RSI > 50 → 确认趋势方向为强势；
  2. 等待 KDJ 回调到低位出现金叉；
  3. 作为**顺势入场或加仓**时机。

### 四、KDJ 风洞（反转风洞）：高阶形态

- 定义：**K 线与 D 线在短时间内连续两次交叉**所夹出的一个**窄小空间**。
- 坊间说法：**风洞越小越值钱**（作者说可自行观察验证）。
- **最可靠周期是周 K 线图**——周线级别的风洞信号稳定性更高，能有效过滤日线级别短期噪音产生的假信号。
- 机制：捕捉**多空力量短暂契合后、强势一方重新掌握主导权**的关键节点，比单一金叉死叉更精细。

### 五、参数调整的取舍

- 计算周期**越小** → 反应越灵敏、可**降低钝化**现象，但**虚假信号越多**。
- 计算周期**越长** → 指标**滞后性越严重**。
- 作者提醒：任何技术形态都不是 100% 准确。

## 实用建议

1. **按交易周期选指标**：短线用 KDJ 的灵敏，波段用 RSI 的稳定，别混着用同一套规则。
2. **金叉看低位、死叉看高位**：脱离位置谈 KDJ 交叉，信号质量会大幅下降。
3. **强趋势中别被超买吓跑**：钝化是强势证明，用钝化消失确认转弱。
4. **组合而非堆叠**：RSI 定方向 + KDJ 找点；不要再叠一个同类摆荡指标。
5. **风洞优先看周线**，且把它当精细信号，不是确定性形态。
