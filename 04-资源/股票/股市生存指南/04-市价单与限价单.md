# 市价单与限价单

> 原视频：[《股市生存指南》第4课，A股市场规则。](https://www.bilibili.com/video/BV1NNbK6KEEo) · B站 · 2分36秒 · UP：机油手_交易员版

## 一句话概括

> A股两种下单模式：**市价单拼速度**（立刻成交，价格不可控），**限价单拼精准**（控制成本，但可能不成交）。新手建议多用限价单——它能有效克制冲动交易。

## 核心内容

| | **市价单** | **限价单** |
| --- | --- | --- |
| 怎么成交 | 按当下市场**实时价格立刻成交** | 手动设定价格，**市场价格走到你指定的价位才生效** |
| 最大优点 | 成交效率高，保证快速买卖 | **牢牢控制交易成本**，避免盲目追高、被动割肉 |
| 代价 | 行情震荡剧烈时，**最终成交价会和看到的价格有出入** | 价格到不了目标位，**单子会一直挂着不成交** |
| 适用场景 | 十分看好（或看空）个股，急需完成交易 | 有明确的目标价位 |

> 一句话：**市价单拼速度，限价单拼精准。**

**视频给新手的建议：多用限价单。** 理由是它能克制冲动交易——你必须先想清楚愿意出什么价，才能挂单。

### 限价单为什么总不成交

![[市价单与限价单-不成交的常见原因.jpg]]

*视频 01:49 —— 最常见的原因就是价位没给到位。*

1. **最常见的：价位设置不当**
   - 股价持续**上涨**时，你的买入价低于现价 → 无法成交
   - 股价一路**下跌**时，你的卖出价高于现价 → 同样卖不出去
2. **早盘集合竞价阶段容易挂单失效**：比如 9:19 看到个股即将涨停就挂单买入，但主力在临近 **9:20 突然撤销涨停买单**，股价快速回落，你的挂单就会因为价位偏高而成交失败。

> 第 2 点在 [[03-集合竞价]] 里有完整解释——9:20 之前挂单可撤，所以那里的价格可能是假的。

## 关键摘录

| 原文 | 我的想法 |
| --- | --- |
| 「市价单拼速度，限价单拼精准。」 | 八个字说清了两者的分工。**它本质上是一道选择题：你要确定性（成交）还是控制权（价格）？** |
| 「建议新手多用现价单，能有效克制冲动交易。」 | 理由很实在——限价单强制你在下单前先定出一个价格，这一步就把「随手买」挡掉了大半。 |
| 「如果股价始终达不到目标价位，单子就会一直挂单。」 | 提醒了限价单的反面代价：**为了控制价格，你放弃了成交的可能性**。用它的人必须接受「可能完全错过」。 |

## 我的理解

- 这两种单子其实是**「确定性」和「控制权」的取舍**，不可能同时拿到。市价单给你「一定成交」，代价是价格随行就市；限价单给你「一定价格」，代价是可能永远等不到。想清楚自己这一笔要什么，再选单型。
- **新手常见错误正好是搞反**：想确保成交却用了限价单（结果挂一天不成交），想控制价格却用了市价单（结果成交在坏价位）。视频只说了「多用限价单」，但那是有前提的——**前提是你的目标是控制成本，而不是立刻建仓**。急着进场的场景用限价单只会错过。
- 限价单不成交的第二个原因（集合竞价假单）说明：**限价单在早盘竞价阶段是「被动挨打」的一方**。你按 9:19 的假价格挂单，主力撤单后价格回落，你的单子就废了——这不是挂单技巧问题，是信息劣势的必然结果。
- 与 [[04-T+1交易制度]] 合起来看有个重要推论：**A股当天买入的仓位当天卖不掉**，所以「限价单没成交」有时反而是好事——它挡住了你当天反悔的操作。
