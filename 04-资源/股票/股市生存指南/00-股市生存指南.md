## 建议阅读顺序

这个系列是**层层递进**的，按课号读收益最大：

**第一层 · 建立认知（第1–2课）**
[[01-买股票就是买公司|买股票就是买公司]] → [[02-A股市场五大参与者|A股市场五大参与者]]
先理解「股票是什么」和「你在跟谁博弈」。

**第二层 · 认识市场规则（第3–4课）**
[[03-A股三大交易所|A股三大交易所]] · [[03-集合竞价|集合竞价]] · [[04-市价单与限价单|市价单与限价单]] · [[04-T+1交易制度|T+1交易制度]]
知道这个游戏怎么运转、你的单子是怎么成交的。

**第三层 · 看懂工具（第5–10课）**
[[05-股票软件界面速读|股票软件界面速读]] → [[06-K线的构成|K线的构成]] → [[07-单根K线形态|单根K线形态]] → [[08-成交量与量价关系|成交量与量价关系]] → [[09-移动平均线|移动平均线]] → [[10-压力位与支撑位|压力位与支撑位]]
从「界面地图」到「看盘语言」，这是整个系列最硬核的部分。

**第四层 · 建立体系（第11–12课）**
[[11-交易模式的选择|交易模式的选择]] → [[12-左侧交易与右侧交易|左侧交易与右侧交易]] · [[12-移动止损|移动止损]]
先定赛道（交易模式），再学具体动作（入场位置 + 出场规则）。

**第五层 · 看懂全局与盘口（第13–15、17–18课）**
[[13-七大指数|七大指数]] → [[14-分时界面速读|分时界面速读]] → [[15-集合竞价定价机制|集合竞价定价机制]] → [[17-内盘与外盘|内盘与外盘]] → [[18-内外盘实战五式|内外盘实战五式]]
先用指数判断市场整体状态，再放大到个股分时页：集合竞价区展开到「开盘价怎么算出来」，成交明细的红绿再展开到「谁在主动成交」，最后学会识别这套数据怎么被做假。

**第六层 · 短线筛选指标（第19–23课）**
[[19-委比|委比]] → [[20-量比|量比]] → [[21-量比实战应用|量比实战应用]] → [[22-换手率|换手率]] → [[23-换手率应用思维|换手率应用思维]]
从「挂单意愿」到「竞价量能」再到「筹码交换比例」，三层指标串成短线筛选链；共同前提是——它们都是筛选器，不是决策器。

**第七层 · 估值与财报（第24–29课）**
[[24-市盈率|市盈率]] → [[25-PE陷阱|PE陷阱]] → [[26-财报速读|财报速读]] → [[27-净资产收益率ROE|净资产收益率ROE]]
先会用估值尺子，再知道尺子什么时候失真，最后学会用财报排雷。

**第八层 · 技术指标与筹码（第30–36课）**
[[30-MACD|MACD]] → [[31-MACD实战应用|MACD实战应用]] → [[32-RSI与MACD|RSI与MACD]] → [[33-KDJ|KDJ]] → [[34-布林线BOLL|布林线BOLL]] → [[35-筹码分布|筹码分布]] → [[36-筹码峰实战应用|筹码峰实战应用]]
从动能指标到摆荡指标再到成本分布，层层逼近「主力在做什么」；共同底线是——指标是确认工具，不是买卖触发器。

> 补读：[[03-集合竞价|集合竞价]] 是同一机制的「现象层」（9:20 分水岭、假单诱多），与第 15 课的「定价层」互补。
