# 内盘与外盘

> 原视频：[《股市生存指南》第17课，看懂内盘和外盘](https://www.douyin.com/video/7651971357458189622) · 抖音 · 4分22秒 · UP：机油手

## 一句话概括

> 内外盘统计的是**已成交单子里谁更主动**：买方主动吃卖单＝**外盘**（红），卖方主动砸买单＝**内盘**（绿），两者相加就是当日成交量。一般行情里「外盘大偏多、内盘大偏空」，但**一旦涨跌停封板数据就失效**，主力还能对倒把数字做反。作者的原话最值得记：「你懂了，那就是你懂了；但如果你信了，那你大概率亏得裤衩都不剩。」

## 核心内容

### 二、⭐ 定义：关键词是「主动」

| | 外盘 | 内盘 |
| --- | --- | --- |
| 含义 | **主动性买入**的成交量 | **主动性卖出**的成交量 |
| 谁主动 | 买方主动以**卖一及以上**报价吃单 | 卖方主动以**买一及以下**报价砸单 |
| 颜色 / 多空 | 红色 / 多头（拿钱想买进去的人） | 绿色 / 空头（拿股票想卖出来的人） |
| 统计范围 | **只算已成交**，挂单不算 | 同左 |

- 记忆法（视频原话）：**内盘＝里面拿股票的人想卖出来，是空头，所以绿色；外盘＝拿着钱的人想买进去，是多头，所以红色**。

![[内外盘-定义对照.jpg]]

*视频 01:45 —— 绿色标注「内盘：拿股票想卖的人」，黄色标注「外盘：拿钱想买股票的人」。*

### 三、示例推演：一分钱的让步决定计入哪个盘

1. 想以 **74.00 元买 100 手**，但最低卖价是 **74.01 元** → 双方都不让步就没有成交。
2. 你加一分钱挂 **74.01 买入 100 手** → 这是**主动买**，这 100 手计入**外盘**，单位是手。
3. 你的对手方在 74.01 卖出那 100 手，属于**被动卖**（视频说「被动买」，见文末校对说明）。
4. 反过来：想以 **74.01 卖出 100 手**，但买方最多出 74.00 → 你降价一分挂 74.00 卖出 → **主动卖**，计入**内盘**。

![[内外盘-主动成交示例.jpg]]

*视频 00:45 —— 红笔圈出盘口「卖方 / 买方」，字幕「假设买方和卖方都不让步」，讲主动成交成立的前提。*

### 四、统计校验：内盘 + 外盘 = 当日成交量

- 视频实例（当时称「烽火通信」）：**内盘 76.4 万手 + 外盘 85.13 万手 = 161.53 万手**，正好是当天全部成交量。
- 点开「成交」饼状图：红色主动买＝外盘，绿色主动卖＝内盘。
- **这条是检验自己有没有理解错的快捷方法**：两数相加若不等于当日成交量，说明看错了口径。

![[内外盘-盘口看跌.jpg]]

*视频 03:15 —— 盘口与分时图示例，字幕「就说这股票要跌」，对应「内盘大于外盘」的常规解读。*

### 五、常规分析及其边界

- 作者的推理链：股价上涨靠买方不断抬价（10 元 → 11 元 → 12 元），愿意抬价是因为预期还会涨。
- 因此他强调**「一般情况下」**：外盘 > 内盘（主动买多于主动卖）→ 迫不及待买入的人更多 → 后期**涨的概率相对大**；内盘 > 外盘 → **跌的概率相对大**。
- ⚠️ 这是**概率性、相关性**描述，不是因果铁律。视频没有给出统计样本、时间窗口或胜率数据，不能当作买卖信号单独使用。

### 六、⭐ 特殊情况：封板后数据失效

- 视频实例：「光华科技」加速上涨、一字板涨停时，**内盘 4 万多手、外盘 0**。不能一看内盘大于外盘就说要跌。
- **机制**：涨停时上方卖单为零，想主动买也买不到，只能挂在买一等着别人主动卖 → 盘上只剩主动卖数据，主动买为零；跌停同理反向。
- **结论**：涨跌停封板状态下内外盘失去常规含义，该看的是**封单量与成交额**，不是红绿比例。

### 七、作者的警告：主力能把数据做反

- 原话：「如果你懂了，那就是你懂了；但如果你信了，那你大概率亏得裤衩都不剩。」
- 主力知道散户会用内外盘判断涨跌，就可能通过技术手段把数据做成反的，尤其在**高度控盘、准备「市值管理」**的时候。
- 具体做盘手法与识别方法 → 作者留到第 18 课。

## 实用建议

1. **先校验口径**：内盘 + 外盘是否等于当日成交量，对不上就别用。
2. **只在不封板的连续竞价阶段用**；涨跌停、一字板、临停状态下直接忽略内外盘。
3. **当情绪线索，不当信号**：必须和股价位置、成交量、分时走势一起看；低位外盘持续大且温和放量，与高位外盘巨大但股价滞涨，含义完全相反。
4. **看背离**：外盘大但价格不涨、内盘大但价格跌不动，优先怀疑诱多 / 洗盘，而不是顺着数字下单。
5. **记住作者的结论**：懂机制 ≠ 可以照数字交易。第 18 课讲识别主力欺骗手法，值得接着看。
