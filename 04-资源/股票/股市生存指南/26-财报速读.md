# 财报速读

> 原视频：[《股市生存指南》第26课，快速获取财务报表信息](https://www.douyin.com/video/7658707778206223651) · 抖音 · 6分39秒 · UP：机油手

## 一句话概括

> 财报对散户的用途**不是算公司值多少钱，而是排雷、看真假**：只需盯三张表——利润表看营收/毛利率/归母与扣非净利润，资产负债表看负债率/存货/应收账款，现金流量表看经营活动现金流。核心铁律：**利润只是账面，现金才是事实**；高利润但现金流为负＝纸面富贵。

## 核心内容

### 一、为什么学：面对爆炸数据先别产生幻想

- 视频开场：江波龙半年报业绩预告出现「百分之六万多」的夸张数字，配合刚学的市盈率一算，容易让人脑补「AI 核心资产 / 存储大牛市」。
- 作者提醒：面对异常数据，**先弄清楚这家公司究竟发生了什么**，再谈估值。
- 路径：同花顺手机端下滑 → 简况/F10 → 财务分析 → 常用指标 → 更多。

### 二、⭐ 心态定位：财报是用来排雷的

- 作者自述：金融科班 + 十余年股龄，作为短线选手「只要不套住我，基本不会深入研究财报」。
- 但作为**名义上的投资者**，判断公司好坏要结合**基本面 / 技术面 / 消息面 / 政策面**四方面，研究基本面绕不开财报。
- 关键那句：**财报对我们来说，不是用来研究公司值多少钱，而是用来排雷以及看清真假的**。
- 不需要懂会计，只要回答三件事：**赚的钱是不是真的、经营是不是健康、有没有偷偷挖坑**。

### 三、利润表：锁定四个关键词

| 指标 | 看什么 | 陷阱 |
| --- | --- | --- |
| **营业收入** | 正增长一般代表盘子实实在在做大、出货规模扩张 | 只是「一般情况下」，需配合其他指标 |
| **毛利率** | 持续走高 → 要么生产成本大降，要么产品利润回暖 | 单独看不能定性 |
| **归母净利润** | 宽口径：所有净收益都算，含卖资产、卖子公司等一次性利润 | 大涨可能是一次性收益（见 [[25-PE陷阱]] 赛威电子案例） |
| **扣非净利润** | 扣除非经常性损益后，主业真正赚的钱 | — |

- **判断标准**：扣非净利润连续多个报告期上涨 → 主业经营不错、越赚越多；归母净利润大涨但扣非不涨甚至下跌 → **假增长**。

### 四、资产负债表：锁定三个关键词

- 利润表反映**一段时间**的表现，资产负债表反映**某个时间节点**的全部家底和负债。
- **资产负债率**：如 60% 即负债占总资产 60%。要结合**行业平均**看：景气阶段靠杠杆放大盈利无可厚非，但周期反转时远高于行业平均的负债是隐患。
- **存货**：上行周期里存货多叫硬资产、越放越值钱；下行周期巨额存货意味着**巨额减值风险**（中长期风险）。
- **应收账款**（作者说「这一项就很棒」）：虚构收入graded的经典路径——把滞销产品高价卖给表面无关、实则自己控制的空壳公司，只要签合同，财报上立刻凭空多出营业收入和净利润，钱全变成**应收账款**；几年后做坏账一笔勾销。

### 五、现金流量表：经营活动现金流是照妖镜

- 只看一项：**经营活动现金流**（日常做买卖回笼的现金）。
- 老股民说「利润可以作假，现金流骗不了人」：
  - 利润采用**权责发生制**，货卖出去就计入利润，哪怕没收钱；
  - 现金流只认**实实在在到账**的钱。
- 作者比喻：粉饰净利润对精明财务人员来说「比开美颜瘦脸还简单」，但经营现金流几乎无法造假。
- **铁律**：**利润只是账面，现金才是事实**——长期扣非净利润要能持续匹配经营现金流；高利润但现金流为负叫**纸面富贵**（好比天天吃香喝辣、信用卡总还不上）。

### 六、三张表给出的四个判断

1. **营收**确认生意是否真实扩张（而非单纯利润跳涨）
2. **两个净利润**对比确认主业利润不是一次性收益
3. **毛利率**判断盈利质量，串联刚学的估值（[[24-市盈率]]）
4. **存货 / 负债率 / 现金流**判断有无暗藏风险

数据都达标 → 基本面起码健康；任何一项亮红灯 → 谨慎对待。作者最后把开篇江波龙的爆炸数据留作练习。

## 实用建议

1. **先看扣非、再看归母**：两者背离就是「假增长」的第一信号。
2. **把经营现金流当照妖镜**：高利润 + 负现金流，直接降级观察。
3. **应收账款异常膨胀要警惕**：尤其伴随营收暴增而现金没回来时。
4. **负债率和存货必须结合行业周期**：同一个数字在景气上行和下行期含义相反。
5. **财报是排雷工具，不是估值工具**：估值用 PE 等（[[24-市盈率]]），财报负责确认数据可信。
