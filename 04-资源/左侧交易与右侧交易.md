# 左侧交易与右侧交易

> 原视频：[《股市生存指南》第12课](https://www.bilibili.com/video/BV1t6HS6yE8d) · B站 · 3分22秒 · UP：机油手_交易员版

## 一句话概括

> 左侧是「跌着买、赌反弹」，右侧是「涨起来再跟、赚趋势」——两者都能亏，真正的分水岭不在选哪边，而在**有没有提前定好出场规则**。

## 核心内容

把一段行情想成一个 **V 字形**：下跌那一段叫**左侧**，上涨那一段叫**右侧**。

![[左侧交易与右侧交易-左右侧示意.jpg]]

*视频 00:25 —— 紫色框内就是完整的一轮：左边下跌段是「左侧交易」的入场区，右边上涨段是「右侧交易」的入场区。*

| | 左侧交易 | 右侧交易 |
| --- | --- | --- |
| 入场时机 | 下跌途中买入，抄底 | 企稳反弹、趋势形成后买入 |
| 拿到的好处 | 真抄到底则成本极低，利润空间大 | 趋势明朗，跟随趋势胜率更高 |
| 典型的死法 | 抄在半山腰 → 越跌越补 → 子弹打光 → 死扛 | 看趋势好就浮盈加仓 → 追高 → 一转折套在山顶 |
| 失败的根因 | **不知道底在哪**，还用补仓对抗不确定性 | **不知道顶在哪**，还用加仓放大贪婪 |

**散户做右侧最常见的完整亏损路径**（视频里的例子，值得记住）：

13 买入 → 15 怕见顶卖出 → 涨到 18 后悔追回 → 21 又怕了卖出 → 涨到 25 认定是长牛 → **26 狠下心重仓买回** → 开始下跌 → 23 不舍得 → 20 不舍得 → 跌穿成本线 → 卖也不是不卖也不是 → 利润全吐回甚至巨亏。

![[左侧交易与右侧交易-散户亏损路径.jpg]]

*视频 02:05 —— 图上把每一步都标了出来：13 买入 → 15 卖出 → 18 买入 → 21 卖出 → **26 大笔买入** → 23 → 20 → 17 → 16，跌穿成本。*

注意这条路径的关键：**每一次操作都有当时看起来合理的理由**，但合起来必然亏损。问题不在判断，在于全程没有一个**事先定好的出场线**。

## 关键摘录

| 原文 | 我的想法 |
| --- | --- |
| 「左侧交易如果没把握好机会容易抄在半山腰，为了补仓拉低成本选择越跌越补，结果越补越跌。」 | 补仓是在**用加码对抗不确定性**。如果买入理由没变，补仓合理；如果只是因为"跌了所以更便宜"，那是在赌。 |
| 「趋势明朗，跟随趋势更容易赚钱。」 | 右侧的代价是**用利润换确定性**——入场贵了，但胜率高。这是笔交易，不是缺点。 |
| 「在跟随的过程中看到趋势好，觉得之前入场少了，于是选择浮盈加仓疯狂追高。」 | 这是右侧最隐蔽的陷阱：**浮盈会让人觉得自己是对的**，于是越涨越加，成本被抬到最后一次买入的价位上。 |

## 我的理解

- **左/右不是策略，只是入场位置。** 单独讨论"做左侧还是右侧"没意义——两边都有人稳定赚钱，也都有人稳定亏钱。真正的差别在于：赚钱的人**在买入的那一刻就已经知道自己在什么价位认输**。
- 视频里那条 13→26→被套的路径，每一步都不是因为选错了左还是右，而是因为**每次决策都在临场重新判断**。临场判断 = 情绪决策，长期必输。
- 对我更有用的问法不是"我做左侧还是右侧"，而是"**我这一笔的止损线在哪、会不会随价格上涨而上移**"。前者是分类，后者是规则。

## 可行动的结论

- [ ] 每次买入前先写下止损位，写不出来的就不买
- [ ] 检查自己有没有「越跌越补」的习惯，明确它是有理由的还是单纯的摊低成本
- [ ] 明确一条纪律：**不在上涨途中加仓**（右侧的浮盈加仓是把盈利变亏损的主要通道）
