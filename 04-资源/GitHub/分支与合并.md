# 分支与合并

> 原视频：[GitHub 零基础终极教程](https://v.douyin.com/QX-OjYMAQk4/) · 抖音 · 37分30秒 · UP：木子不写代码

## 一句话概括

> 分支机制解决的是**多人并行开发如何不互相等待**：每个人在自己分支上改，通过 Pull Request 请求合并到 main，评审通过才合并；Tag 则把某个提交冻结成一个可下载的版本。

## 核心内容

### 提交（commit）= 保存一次代码

动画里每一个绿点就是一次提交。「我修了一个 bug，提交一次，就保存了这次修 bug 的代码」。

一个人开发时这只是普通的保存。多人开发时，它变成了版本管理的最小单位。

### 分支（branch）= 并行开发的容器

![[分支与合并-并行开发示意图.jpg]]

*视频 13:30 —— 左侧是提交点主线，右侧标注了 `commit 提交：保存一次代码` 与 `branch 分支：新的工作线`，中间是 main 与 fix-login 两条并行线。*

**问题场景（原片的叙述方式）**：

> 「总不能每次他要等我开发完，我再把代码给他，他开发完再给我，我再继续开发吧？这样太浪费时间，太没效率了」

**解法**：任何人在自己的分支上开发，互不干扰。分支创建的那一刻，会自动包含当时 main 上最新一次提交的全部内容——所以新分支不需要额外同步。

### Pull Request = 请求合并，不是直接合并

贡献者在自己的分支上修完 bug，想并回 main，要发起 PR。PR 的作用是**让其他人先看一眼这个改动**。

评审有两条路：

| 情况 | 处理 |
| --- | --- |
| 改得好，没问题 | Merge，合并到 main |
| 改得不好，有问题 | 打回，贡献者继续改，再提一次 PR |

**PR 机制的价值就在这个「门」上**：任何改动进主干前都有人过一遍，main 始终保持可用。

### 合并之后：main 是唯一的真相

各自在各自分支上工作，最后都合并到 main。**最终 main 分支上会包含所有新的功能和所有新的 bug 修复。**

### 分支命名的社区惯例

| 前缀 | 用途 |
| --- | --- |
| `fix/xxx` | 修 bug |
| `feat/xxx` | 加新功能（feat = feature 特性） |
| `docs/xxx` | 改文档 |

**这些不是强制规定，是社区默认俗成的规矩。** 作用是让人一眼看出这个分支要干什么。

### Tag = 把提交冻结成版本

版本足够稳定时（有新功能、bug 也修完了），给这个提交打一个 Tag，比如 `v2.5.23`。

**Tag 与 commit 的区别**：commit 会继续往前跑，Tag 永远指向那个固定的提交。用户在 Releases 页面下载到的，就是这个被冻结的代码状态。

**语义化版本号的读法**（原片的解释）：

```
2  .  5  .  23
│     │     └── 修复版本
│     └──────── 功能版本
└────────────── 大的版本更新
```

## 关键摘录

| 原文 | 我的想法 |
| --- | --- |
| 「我们应该能够并行开发……他开发他的，我开发我的，然后最后我们一起汇总」 | 并行开发是 Git 相对 SVN 时代的根本改进，代价是必须理解合并 |
| 「这个分支在他创建的瞬间，就保存了我最近一个提交包含的所有修改和代码」 | 新分支自动含最新提交，所以「开分支」不需要额外同步动作 |
| 「要么合并，要么打回让他继续改」 | PR 是一个质量闸门，不是「提交申请」那么简单 |
| 「标签永远对应了这个 commit」 | Tag 是不可变指针，这是它能被当版本号用的前提 |

## 我的理解

- **这一章是全片信息密度最高的一段。** 用一个动画把提交、分支、PR、合并、Tag 五件事串成一个故事，比逐个讲定义有效得多。**如果只看一节，看这节。**
- **「分支存在的理由是并行」这个逻辑链是核心。** 原片先讲「一个人工作没问题」，再讲「多人不行」，再讲「分支解决」，这个递进顺序本身就说明了为什么需要版本控制系统——不是为了「存代码」，是为了「多人协作」。
- **PR 的设计本质是「代码评审的载体」。** 它把 Git 的合并能力和团队的评审流程绑在了一起。这解释了为什么即使只有一个人开发，团队规范也要求走 PR。
- **原片没讲的两件事**（对零基础反而够用，但对实际使用是缺口）：**合并冲突怎么解**、**分支合并后如何清理**。
- **Tag 和 Branch 名字都叫「分支」容易混**：分支是会移动的活指针，Tag 是钉死的。这点原片讲清楚了。
