# 股票软件界面速读

> 原视频：[《股市生存指南》第5课，看懂手机炒股界面](https://www.bilibili.com/video/BV1xAbK6iEPQ) · B站 · 5分4秒 · UP：机油手_交易员版

## 一句话概括

> 个股界面密密麻麻的数据，其实只分成 **5 个板块**。认全这 5 块，看盘就不再一脸懵。

## 核心内容

![[股票软件界面速读-五大板块.jpg]]

*视频 00:30 —— 界面顶部标注了五个板块：① 名称及代码 ② 股价涨跌幅 ③ 盘口指标 ④ K线及成交量 ⑤ 买卖明细。*

### ① 名称及代码

**代码开头直接告诉你它在哪个交易所、哪个板块**（回顾 [[A股三大交易所]]）：

- 贵州茅台 `600519` → `60` 开头 = **上交所主板**

### ② 股价与涨跌幅

| 显示项 | 含义 |
| --- | --- |
| 现价（如 1326.00） | 当前股价 |
| 涨跌额 / 涨跌幅 | **红色 = 今日上涨，绿色 = 今日下跌**（A股配色） |
| 高 / 低 | 当天交易日内的最高价、最低价 |
| 开 | 当天开盘价 |

**两个容易忽略的点：**

1. **买入最低单位是「一手」= 100 股。** 茅台 1326 元 → 买 1 手就要约 13 万。这直接决定了「哪些票我根本买不起 1 手」。
2. **开盘价不一定等于昨天的收盘价**——它是由当天 **9:15–9:25 集合竞价**形成的（见 [[集合竞价]]）。

### ③ 盘口指标（基本面速览）

市值、换手率、**市盈率 PE** 等财报信息，用途是**快速判断这家企业估值贵不贵**。视频明确说每个指标的详细含义后面会单独讲，本课不展开。

### ④ K线及成交量

| 元素 | 含义 |
| --- | --- |
| **分时图**（黑色波浪线） | 当天**每分钟**一个点，全天 4 小时 = 240 个点连成的实时价格线 |
| **分时黄色均线** | 当天的**平均成交价格** |
| **日K线** | 以天为单位，一天一根柱子；**涨红跌绿** |
| 周K / 月K | 换时间尺度，原理相同 |
| **成交量** | K 线下方红绿柱子，越高 = 当日成交量越大 |

> ⚠️ 注意：这里的「黄色均线」是**当日成交均价**，和第 9 课要讲的 MA 均线（多日收盘价平均）**不是一回事**。

### ⑤ 买卖明细（盘口挂单 / 卖盘买盘）

软件空间有限，一般只显示 **卖1–卖5** 和 **买1–买5**。

| | 是什么 | 特点 |
| --- | --- | --- |
| **卖一** | 当前所有卖出挂单中**出价最低**的 | **最容易成交** |
| **买一** | 当前所有买入挂单中**出价最高**的 | 最容易成交 |

**只有当卖一价和买一价一致时，才能成交。** 股票是投资者之间的交易——有人卖，才有人买得到。

**快速成交技巧**（视频给的实用招）：想快点卖出，就把价格设得**比买一更低**，或直接按买一价挂单；快速买进同理（按卖一价或更高挂）。

## 我的理解

- 这五个板块对应的是**五个不同层级的判断**，新手的问题往往出在只看第二层：

  | 板块 | 层级 | 回答什么问题 |
  | --- | --- | --- |
  | 代码 | 规则层 | 它在哪个交易所/板块？（涨跌幅 10/20/30%） |
  | 股价涨跌 | 情绪层 | 今天发生了什么？ |
  | 盘口指标 | 基本面层 | 这家公司贵不贵？ |
  | K线/成交量 | 技术层 | 走势和资金是什么状态？ |
  | 买卖五档 | 微观结构层 | 此刻谁在挂什么价？ |

  盯涨跌幅的人永远在读第一层结论，而后面三层才是原因。

- **「分时黄线 ≠ MA 均线」这个区分值得单独记住。** 两个都被叫「均线」：黄线是**当天**的成交均价（相当于今天所有买家的平均成本线），MA 是**多日**收盘价的平均（趋势线）。混用会导致完全错的判断。
- 五档的实用价值被低估。它其实是 [[市价单与限价单]] 的微观版本：**想快就用价格换时间**（卖出挂买一或更低、买入挂卖一或更高），想省钱就用限价单等。同一道选择题，一个是下单方式，一个是挂单价位。
- 一个提醒：**「一手 = 100 股」直接决定了资金门槛**。这不是基础知识，而是仓位管理的前提——只有 1 万块的人无法用「分批建仓」这套方法去买 1300 元的股票。

## 可行动的结论

- [ ] 对照自己的炒股软件，逐块认出这 5 个区域，确认没有看不懂的地方
- [ ] 算一下自己账户的可用资金 ÷ 100，就知道自己单笔最多能买哪个价位的票
- [ ] 下次挂单前先看五档：卖一/买一在哪里，再决定挂什么价
