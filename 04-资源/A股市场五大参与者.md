# A股市场五大参与者

> 原视频：[《股市生存指南》第2课，股市5大核心参与者](https://www.bilibili.com/video/BV1rCtN6xE8X) · B站 · 5分31秒 · UP：机油手_交易员版

## 一句话概括

> 你每一笔交易都有一个**对手盘**。A股不是「大家一起赚钱」的市场，而是零和博弈——**分不清谁是猎人谁是猎物，亏钱就成了必然。**

## 核心内容

### 前提：这是零和博弈

市场里有人赚钱，就一定有人亏钱（短期意义上）。所以第一件该搞清楚的不是「买什么」，而是「**我在和谁交易**」。

> 股市里最大的风险从来不是行情下跌，而是**你不知道谁在和你博弈**。

### 五类参与者

| 参与者 | 特点 | 赚什么钱 | 角色 |
| --- | --- | --- | --- |
| **散户** | 资金量小、无专业研究团队、无固定交易体系；最大问题是**情绪化**——涨了追涨、跌了恐慌割肉 | 通常是被赚的那一方 | 猎物 |
| **机构**（公募/私募/社保/保险） | 体量极大、研究专业、周期长、看基本面；买一只股是看它**三年五年**的业绩和价值 | 企业成长的钱 + 时间复利 | 最稳健的猎人 |
| **游资** | 不做长线、不看基本面，只做短线情绪博弈；快进快出、波段炒作 | **散户情绪化跟风的钱** | 最凶的猎人 |
| **外资**（北向资金） | 风格介于机构与游资之间，整体偏价值，但对市场情绪和短期汇率非常敏感；布局各行业龙头白马 | 趋势差价钱 | 风向引领者 |
| **主力** | 中长期控盘的大资金团队；提前潜伏、长期控盘，走完**洗盘 → 吸筹 → 拉升 → 出货**整套周期 | 完整周期的钱 | 猎人 |

### 怎么识别谁在主导（最实用的部分）

| 你看到的现象 | 大概率是 |
| --- | --- |
| 白马股（长江电力）、宽基 ETF（沪深300 / 上证50）**常年平稳、循序渐进**、很少暴涨暴跌 | **机构**主导 |
| 题材热点板块里**连续涨停、短期暴涨**的个股（新能源、人工智能、消费复苏等题材） | **游资**主导（视频称「90% 都是游资」） |
| 市场或板块**最先异动、最先入场**的资金 | **北向资金**（判断市场强弱的重要参考） |
| 走势**非常规律、底部扎实、慢慢走高**的个股 | **主力**控盘 |

### 散户的生存思路

> 核心只有一句：**不做博弈的炮灰，学会跟随强者。**

- 趋势好、底部扎实的**白马股 / 宽基 ETF** → 跟随**机构**，做稳健长线
- 短期热点明确、情绪稳定的行情 → **轻仓**跟随**游资**，做短线
- 绝不盲目跟风、高位接盘

## 关键摘录

| 原文 | 我的想法 |
| --- | --- |
| 「股市里最大的风险从来不是行情下跌，而是你不知道谁在和你博弈。」 | 散户亏钱通常不是判断错方向，而是**根本没意识到自己在跟一个有资金、信息、组织优势的对手玩**。 |
| 「机构赚的是成长的钱，游资赚的是散户情绪化跟风的钱。」 | 一句话把两类猎人的盈利模式讲透了。**追涨停 = 直接和游资对赌**，这是概率上最差的游戏。 |
| 「我现在买的标的，是谁在主导行情？」 | 一个可执行的动作。比「这股票会不会涨」高级得多——前者是可回答的，后者不可回答。 |

## 我的理解

- **这一课的价值不在那五类名单，而在于把「我在跟谁做对手盘」变成下单前的固定动作。** 名单会变，这个自问的习惯不会过时。
- 「零和博弈」这个前提要划清边界：**短期是零和，长期不是**。指数整体随经济增长向上，长期持有宽基 ETF 的人赚的是企业整体的成长，不是别人的亏损。理解这一点，才不会滑向「股市就是零和骗局」的极端结论。
- 最实用的是那张识别表（白马慢涨=机构 / 涨停潮=游资 / 最先异动=外资 / 底部扎实规律走高=主力）。它把「这股票现在什么状况」从感觉变成了可观察的特征，比只看涨跌幅有用得多。
- 需要泼的一点冷水：**「90% 的涨停背后是游资」这类数字是经验说法，没有出处，别当精确统计用**。方向大概率对，精度别当真。
- 视频说「跟随机构做稳健长线」，隐含前提是**你拿得住**。拿不住的话，跟机构也照样亏——这正好是 [[移动止损]] 那类规则要解决的事。

## 可行动的结论

- [ ] 下单前固定问一句：这个标的是哪种资金在主导？我是在跟随，还是在接盘？
- [ ] 给自选股分个类：哪些是机构主导（白马 / 宽基 ETF），哪些是游资主导（题材涨停股）
- [ ] 写下自己**明确不参与**的领域（比如连续涨停的题材股），并说明理由
