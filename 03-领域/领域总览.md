# 🧭 03-领域

**定义**：需要长期维持标准的事情，没有终点。比如：健康、财务、职业能力、亲密关系、团队管理。

项目是「跑一次」，领域是「一直跑」。

## 每个领域记录什么

- **标准**：做到什么程度算「维持住了」
- **节奏**：多久回顾一次（周 / 月 / 季）
- **指标**：怎么判断状态好还是坏
- **日志**：这个领域里发生的具体事件，链接回 `07-日记`

## 领域 vs 项目

| | 领域 | 项目 |
| --- | --- | --- |
| 终点 | 没有 | 有 |
| 例子 | 保持健康 | 三个月内减到 70kg |
| 失败的样子 | 慢慢滑坡，不易察觉 | 逾期，很明显 |
| 回顾频率 | 定期（月/季） | 随进度 |

> 大部分「项目拖延」的根因，是它背后其实是一个没被定义的领域。先把领域写清楚，项目自然就浮出来了。
